Drilling Depth & Options

1st reaming (13¾") is always included as the base pass. 2nd reaming (17½") and 3rd reaming (22½") are each optional, sequential enlargement passes — 3rd reaming is only meaningful if 2nd reaming is also included.

Depth Segments — Soil Type & Drilling Method

Define the well as one or more depth segments. For each segment, choose the soil type (Soft / Medium / Hard) and the drilling method (Rotary / DTH). The DWSS Rate Analysis Norms (2073) are then applied segment by segment, using the appropriate coefficient tables for each combination. Rotary is used for Soft, Medium and Hard formations; DTH is used for Hard rock only, and produces the final-diameter bore in a single pass, so no reaming is applied for DTH segments.
